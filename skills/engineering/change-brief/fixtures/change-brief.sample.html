Risks

For reviewers. Evidence points at file:line in the change — select to copy.

  • R1 HIGH behavior Floating-point rounding of amount * rate may drift on edge inputs

    Math.round(raw*100)/100 is not exact decimal arithmetic: rates like 1/3 or amounts with many decimals can round unexpectedly. Tests cover 19.99 * 1/3, but amounts near .005 boundaries are untested and binary floats can produce 14.995 -> 15.00 vs 14.99.

    src/calc.js:11

  • R2 MEDIUM logging console.log prints the raw monetary amount

    Raw amounts in server-side logs can be considered sensitive; in enterprise/PCI contexts log content may be retained. Should use the formatted helper or structured logging without the raw value.

    src/calc.js:10

  • R3 MEDIUM behavior Pricing total now includes tax — callers may double-charge

    pricing.ts now adds tax to subtotal. Any other code path that already applied tax would now double-charge. Only this file changed, so reviewers should check remaining callers.

    src/pricing.ts:6
